# 平野孤鸿 全能修改器 v0.2 — 用户手册

## 一、软件简介

《平野孤鸿》全能修改器（woldvein Trainer）是一款专为西山居城建经营游戏《平野孤鸿》(BalladsOfHongye) 开发的游戏修改工具。

**核心特性**：
- 资源修改：9种资源一键+100万、幸福度最大、知名度+1万
- 创造模式：鸿业满级 + 全建筑解锁 + 无限资源 + 升级无限制
- 全局热键：游戏中也可使用热键快速修改（默认启用，需管理员权限）
- 纯内存操作：不修改游戏磁盘任何文件，关闭游戏后效果消失

## 二、系统要求

- 操作系统：Windows 10 / Windows 11（64位）
- 游戏版本：Steam版《平野孤鸿》(AppID: 2656540)
- 运行环境：无需安装，绿色免安装
- 权限建议：以管理员身份运行（热键功能需要）

## 三、快速开始

### 3.1 启动修改器

1. 双击 `woldvein_trainer.exe`（或运行 `python main.py`）
2. 修改器会自动检测游戏进程

### 3.2 启动游戏

方式一：点击修改器顶部的「启动游戏」按钮（通过Steam协议启动）
方式二：手动从Steam启动游戏

### 3.3 注入DLL

1. 游戏启动后，修改器顶部会显示「游戏运行中 (PID: xxxx)」
2. 点击「注入DLL」按钮
3. 提示「DLL注入成功」后即可使用所有功能

> **重要**：必须进入游戏场景（加载存档后）才能使用资源修改和创造模式功能。主菜单时 g_camp 未初始化，修改会失败。

### 3.4 使用功能

| 功能 | 操作方式 |
|------|----------|
| 资源+100万 | 「资源修改」标签页 → 点击对应资源的「+100万」按钮 |
| 自定义资源数量 | 输入数量 → 点击「增加」 |
| 一键全部资源 | 点击「一键全部资源 +100万」 |
| 幸福度最大 | 点击「幸福度最大」 |
| 知名度+1万 | 点击「知名度 +1万」 |
| 创造模式 | 「创造模式」标签页 → 点击「开启创造模式」 |

## 四、功能详解

### 4.1 资源修改

支持9种游戏资源：
- 金钱、木料、矿产、衣物、食物、水、人口、盐、酒

每种资源支持：
- 一键 +100万
- 自定义数量增加

特殊属性：
- 幸福度最大（设为999，等级4）
- 知名度 +1万

### 4.2 创造模式

开启创造模式后同时生效以下功能：

| 功能 | 说明 |
|------|------|
| 鸿业满级 | 鸿业等级直接设为14级（满级），解锁所有等级奖励 |
| 全建筑解锁 | 所有建筑卡片解锁，可建造任何建筑（不受科技/繁荣度限制） |
| 无限资源 | 建造建筑不消耗任何资源 |
| 升级无限制 | 建筑可升级到最高级，无等级/条件限制 |

**关闭创造模式**：再次点击按钮，所有hook还原，游戏恢复原版逻辑。

### 4.3 全局热键

| 热键 | 功能 |
|------|------|
| Ctrl+F1 | 金钱 +100万 |
| Ctrl+F2 | 食物 +100万 |
| Ctrl+F3 | 水 +100万 |
| Ctrl+F4 | 衣物 +100万 |
| Ctrl+F5 | 木材 +100万 |
| Ctrl+F6 | 矿物 +100万 |
| Ctrl+F7 | 盐 +100万 |
| Ctrl+F8 | 酒 +100万 |
| Ctrl+F9 | 知名度 +1万 |
| Ctrl+F10 | 创造模式开关 |
| Ctrl+F12 | 幸福度最大 |

> 热键需要以管理员身份运行修改器才能生效。热键功能依赖 `keyboard` 库，源码运行需 `pip install keyboard`。修改器启动后热键默认启用，可在「热键设置」标签页手动关闭。

## 五、技术原理

### 5.1 架构

```
修改器(Python/tkinter)
    ↓ DLL注入
游戏进程(BalladsOfHongye.exe)
    ↓ inline-hook lua_pcall
Lua5X64.dll (Lua虚拟机)
    ↓ 执行Lua代码
游戏全局变量 (g_camp, g_BuildingWorldModule, etc.)
```

### 5.2 DLL注入

- 使用 Windows API：OpenProcess → VirtualAllocEx → WriteProcessMemory → CreateRemoteThread(LoadLibraryW)
- DLL 内 inline-hook Lua5X64.dll 的 `lua_pcall` 函数（14字节绝对跳转框架）
- 通过命令文件机制（lua_cmd.txt / lua_result.txt）与Python端通信

### 5.3 创造模式实现

- 资源不扣：散件覆盖机制（每3秒重置资源为目标数额）
- 全建筑解锁：hook `GetUnlockState` + `SetBuildingCardState` + `AddOtherBuildings` + UI刷新事件（UI只显示最高级建筑）
- 鸿业满级：hook `IsSatisfied` / `GetBoom` + 直接 `setBoom(14)` + 奖励解锁
- 升级无限制：hook `CheckCanUpgradeBuilding`

## 六、常见问题

### Q: 点击注入DLL后提示失败？
A: 
1. 确认游戏已启动并进入主菜单
2. 尝试以管理员身份运行修改器
3. 检查杀毒软件是否拦截了DLL注入

### Q: 资源修改提示失败？
A: 必须进入游戏场景（加载存档后）才能修改。主菜单时 `g_camp` 未初始化。

### Q: 创造模式开启后建筑还是灰的？
A: 尝试切换建筑分类标签页刷新UI，或重新打开建造面板。创造模式的解锁是即时的，但UI可能需要刷新。

### Q: 关闭修改器后游戏会受影响吗？
A: 所有修改只存在于内存中，不修改磁盘游戏文件。关闭修改器后，DLL 仍驻留在游戏进程中（lua_pcall hook 保持），直到游戏退出后完全消失。如需彻底还原，关闭游戏即可。

### Q: 热键不生效？
A: 
1. 以管理员身份运行修改器
2. 在「热键设置」标签页确认热键已启用
3. 源码运行需安装 `pip install keyboard`

## 七、安全与免责

### 7.1 安全说明

- 本软件不修改游戏磁盘任何文件
- 所有修改仅存在于游戏进程内存中
- 不包含任何恶意代码，源码完全开放

### 7.2 杀毒误报

DLL注入技术可能被部分杀毒软件误报为威胁。这是正常现象，因为修改器需要注入到游戏进程中执行代码。

如遇误报：
1. 将修改器目录添加到杀毒软件白名单
2. 或从源码自行编译（`gcc -shared -o woldvein_trainer.dll trainer.c`）

### 7.3 免责声明

- 本软件仅供学习研究和单机游戏体验使用

- 本软件与游戏开发商无关
