## 五、关键Bug修复

### 5.1 时间系统（v0.3重点修复）

| 问题 | 根因 | 修复 |
|------|------|------|
| 速度不受控 | `LUA_RESTORE_TIME_SPEED` 兜底硬写0.016（实机基准2.5）→ ~156倍速 | 还原基准值，无基准时不改动 |
| 越点越快（滚雪球） | 游戏自己改TICK_DELTA_TIMES被当成新基准 | 彻底删除"用当前值当基准"，只认权威值 `define.DAY_TIME_REAL/define.DAY_TICK_COUNT` |
| 时间跳过失控 | `m_nDayStamp` 是年内第几天(1~360)，旧实现当累计天数 | 改用年/月/日推算，回写 `(newMonth-1)*30+newDay` |
| 7月的冬天 | 只hook GetCurSeason，不动日期 | 设置季节时同步日期，月份落入季节区间 |

### 5.2 成就系统

| 问题 | 根因 | 修复 |
|------|------|------|
| 挑战成就不解锁 | `GM_UnlockAllAchievement` 只循环1..99，挑战成就ID>99 | 循环放大到1..300，超时8s→40s |
| Steam不亮 | 只解锁图鉴卡+置unlockState，从未推送平台 | 强制调 `mgr:UnlockAchievement(achId)`（C++→Steam） |
| 探查无输出 | pcall型脚本成功时不return | 补 `return err`（全项目25处） |

### 5.3 灾害系统

- **零天灾/零人祸关不掉**：旧实现把DisasterType数值当键调 `GetActiveDisaster(type)`，键与判活路径不一致 → 改为直读 `block.m_disasterMgr.m_tbDisasters`，用 `dis:IsActive()` 判活 + `dis:SetActive(false)` 关闭
- **灾害分类**：人祸 = DT_CRIME / DT_RIOT / DT_REFUGEE，其余为天灾（实机确认枚举）

### 5.4 其他重要修复

| 问题 | 修复 |
|------|------|
| 知名度修改无效 | 原实现靠猜字段名 → 改用 `g_LReputationMgr:ChangeReputation` + `ChangeReputationBase` 双存储 |
| 单等级建筑（谋士府）点升级播动画 | hook CheckCanUpgradeBuilding先调原始函数，最大等级=1不允许升级 |
| 清空日志按钮无效 | 新增 `logger.clear_log_file()`（关闭句柄→清空→重开），成功弹出提示 |
| 创造模式键名不一致 | `__cm_orig_CheckCanCreateBuilding` → `__cm_orig_CheckCanCreate`（对齐ENABLE保存的键名） |
| trainer.c opcode 0x81错误 | `0x03` → `0x07`（imm32+ModR/M） |
| 打包后通信路径失效 | `sys._MEIPASS` → `%LOCALAPPDATA%\woldvein_trainer\` 固定路径 |
| GBK结果解码失败 | 二进制读 + utf-8失败回退gbk(errors="replace") |
| NPC管理器路径错误 | `m_lActiveCity`（实机nil）→ `g_CityManager:GetActiveCity()` |
| 热键默认值硬编码 | 改用 `get_default_hotkeys()` 统一来源 |
